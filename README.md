# The Funniest Sick Day Excuse — entry

A program/v1 entry for the make.fun "The Funniest Sick Day
Excuse" bounty. `main.py` writes one excuse to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The excuse:

> I'm unwell: I attended yesterday's two-hour meeting in my dream and did the action items. I need today to recover from work I imagined.

Dream labour is still labour; the minutes are available on
request. See `CANDIDATES.md` for the full draft list this
winner was picked from.
